# Лагуна

Интерактивная 3D-карта решений на основе [Stillwater](https://github.com/MalikAhed/water-studio). Точка «Купить пресс?» открывает финансовый стол заказа «Колтуши».

## Запуск

Выполните в корне репозитория:

```powershell
node sea/serve-lagoon.mjs
```

Откройте [лагуну](http://127.0.0.1:4174/) в браузере с WebGL 2. Установка npm-зависимостей для запуска готовой сборки не требуется.

Приблизьтесь колесом к метке «Купить пресс?» до максимального масштаба. Расчёт откроется автоматически. Кнопка «К лагуне» вернёт камеру в прежнее положение.

## Сборка

При изменении кода 3D-сцены выполните из корня репозитория:

```powershell
cd sea/stillwater
npm ci
npm run build -- --base ./
```

Код интерфейса карты находится в `sea/stillwater/src`, текстуры — в `sea/stillwater/public`, финансовый стол — в `dashboard`, расчёт журнала — в `finance.mjs`. Лицензия и сведения об авторах Stillwater находятся в `sea/stillwater`.
